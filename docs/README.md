# JDORFX documentation

This directory contains the maintained public documentation for JDORFX.

- [Setup and testing](setup.md) explains prerequisites, building, installation,
  and troubleshooting.
- [Command reference](command-reference.md) documents command syntax, aliases,
  and unsupported JDOR operations.
- [Animation guide](animation-guide.md) explains the animation model and points
  to executable examples.
- [Image compatibility](image-compatibility.md) documents image, clipboard, and
  printing behavior relative to JDOR.
- [Architecture](architecture.md) describes the command, JavaFX, and threading
  model.
- [Fixes and JDOR differences](fixes-and-differences.md) records intentional
  compatibility behavior and important fixes.
- [Development history](development-history.md) summarizes completed project
  work; it is not the command reference.

Sample-specific instructions live next to the samples they describe. Internal
thesis notes are maintained separately in `thesis_notes.md` and are not part of
the public documentation set.
